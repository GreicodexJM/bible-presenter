# Project Brief: Bible Show 3D Presenter

## Overview
Bible Show is a browser-based application designed to present Bible verses in a visually stunning 3D environment. It leverages web technologies to create dynamic, themed presentations of scripture, suitable for projection or personal use.

## Core Goals
- **Visual Engagement**: Use 3D graphics (Three.js) and shader effects to create immersive backgrounds for text.
- **Ease of Use**: Simple keyboard-based input for looking up verses (e.g., "Gen 1:1").
- **Customization**: Support for theming (backgrounds, fonts, colors) and automatic theme selection based on verse sentiment.
- **Multilingual**: Support for multiple Bible translations.

## Technical Foundation
- **Frontend**: TypeScript with Vite for build tooling.
- **Rendering**: Three.js for the 3D scene and WebGL shaders.
- **Data**: JSON-based Bible databases derived from the `bible_databases` project.
